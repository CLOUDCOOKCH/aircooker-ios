# Contributing

Use English for code and documentation. Discuss API or sync changes before implementation.
Keep changes focused and include tests that reproduce a meaningful failure or verify a contract.
Never add real credentials, private recipes, raw third-party responses, or telemetry.

Use Apache-2.0 compatible dependencies and record their licenses. No contributor licence
assignment is required; contributions are provided under this repository's license.
Follow the local README for build commands. Keep changelog, acceptance evidence and the
feature matrix consistent with the actual code. Passing Linux tests does not establish
Apple device compatibility, third-party service compatibility, or production readiness.

Report security issues using SECURITY.md. Use synthetic fixtures for household data.
